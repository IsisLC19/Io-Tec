## E-commerce TechPança

Aplicação da Loja
- Usando Supabase
- Cruds:
  - Cadastro de Categoria de Produtos,
  - Cadastro de Produtos com foto (Fotos salvas no BD)
  - Cupons de Desconto
  - Promoções (com data de expiração, por produto ou categoria) 
- Gestão de:
	- Vendas
	- Clientes

## O que não precisa ter

- Logística: código, rastreio, transportadora, etc
- Nota fiscal

## Lado do Cliente 

SPA/PWA empacotado

- Estilo KaBuM, 
- Lista de produto com destaque para as promoções, 
- Carrinho de compras,
- Cadastro do cliente no primeiro checkout,
-  Persistências: Api do Supabase e Localstorage
